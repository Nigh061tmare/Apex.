# Repositorio APEX

La web de APEX Engine vive en **`APEX_ENGINE/`**. Trabaja ahí; las instrucciones del proyecto
están en `APEX_ENGINE/CLAUDE.md`.

El resto de la raíz son herramientas locales de otros proyectos (proxy de Stable Diffusion,
puente SillyTavern, mods de WorldBox, scripts de auditoría, copias de seguridad). No las
modifiques salvo que se pida explícitamente.

Vercel publica `APEX_ENGINE/` automáticamente en cada push a `main`
(https://apex-engine-six.vercel.app) y crea una vista previa por cada PR.
