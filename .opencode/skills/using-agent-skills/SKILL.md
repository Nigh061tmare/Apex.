# Auto-Dispatch Meta-Skill

Esta meta-habilidad instruye al agente a analizar de forma totalmente silenciosa y autónoma cada mensaje entrante del usuario y auto-activar la combinación exacta de habilidades requeridas sin pedir permiso previo.
